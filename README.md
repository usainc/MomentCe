Public support and policy pages for MomentCe, an iOS app for birthdays, anniversaries, countdowns, and meaningful date reminders.

## Product Summary

MomentCe helps users keep track of special days and plan reminders around meaningful dates.

## Features Covered By These Pages

- Birthday and anniversary reminders
- Countdown tracking
- Local event data
- Optional iCloud backup behavior
- Notification settings
- AdMob/UMP advertising and consent information
